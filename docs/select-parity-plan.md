# Portable Select and positioning
Approved continuation of parity roadmap. Preserve local generated files, native form semantics and typed styles; NativeSelect remains the original native select. Custom Select maps the separate `select-list` producer contract with native options slot and projected popup choices. No external UI library, no per-choice component files.

1. Producer: reviewed adapter-required select-list anatomy, optional label, trigger/value/chevron, native select and options, popup, reusable hidden option prototype, model/ARIA/disabled/required wiring; preserve existing select. Test before code.
2. Positioning: one emitted local helper; RTL alignment, flip/clamp/available height, scroll/resize/visual viewport, cleanup and caller style preservation. Browser bounds tests.
3. Select adapter: project native option/optgroup text and disabled state, use prototype class/style, maintain native value model/forms/reset/validation; trigger focused with active-descendant listbox navigation, Escape/cancel, Enter/Space/click commit, Tab commit, typeahead, no disabled commits, dynamic options/external model synchronization. Own IDs based on explicit trigger id and popupId. Ensure listeners/observers/watchers dispose.
4. Pinned Nova recipes with owned typed parts; public size and popup placement axes. Compile standalone and companion emission without external UI/position dependencies. Map original Select usage fixtures to compact options slot API and preserve NativeSelect example.
5. Regenerate support/schema/library/gallery and a neutral light/dark select comparison fixture. Nuxt check/build, cross-browser behavior including native form reset, required/fieldset disabled, dynamic options, RTL, collision/mobile and forced colors. Existing full regression suite.
6. Independent architecture review and one fix pass; record limitations: single value, text option content, flat optgroups, no editable filtering or virtualized list. Combobox/Command now use shared searchable adapters over this positioning layer; HoverCard and Tooltip now reuse the same helper with local hover/focus intent and four-side placement.
